# QS-41-Node.js-application-with-yaml-file

This repo containes Kubernetes manifest to deply a Node.js API application with the following feature:

1. Resource management with CPU and memory requests/limits.
2. Secret and configuration injections with kubernetes Secret and ConfigMap
3. Readiness and liveness probes for application health.
4. HPA for autoscaling
5. Internal Service exposure using clusterIp.
